# 联调与首版验收

按同一组输入对照页面、API、持久化数据和工作流。使用[联调数据](examples.json)启动 mock，从[自编短教材](fixtures/network-mini-textbook.md)启动一次真实导入。数据中的考试时钟、ID、答复和部署请求均为合成样例。实际验收填写观察结果。

## 先验两条最短链路

| 项目 | 起点和操作 | 必须看到 |
| --- | --- | --- |
| 联调 1 · 焦点与返回 | 按 `textbook_flow.api` 走 A/B/S。先在 A，打开 B 选段，向 teacher 提问。在 A 开 S，提交一段成果，沿来源返回。 | A 下保存提问和 B 的资料引用。S 有独立记录。返回先恢复 A 的断点，再放出针对本次 S 的解释。点出处打开 S 当时的原文。 |
| 联调 2 · 小教材开放 | 上传短教材，选全书，提交后关浏览器。回来从任务读取发布结果，打开全部节点。 | 后台继续执行到终态。全书、核心路线和每节出处可读。能从 C 先学，A 到 B 的真实前置有理由。移除编排范围内的一节时得到待补材料的结果。 |

第一个会合先用 mock 测应用状态，再用真正的 AgentArts 部署各调用一次。后端牵头记录请求、队列、校验和落库，前端记录界面动作，教学负责人记录流程标识及用到的输入。

## 教材、焦点与理解反馈

| 编号 | 准备与操作 | 通过条件 |
| --- | --- | --- |
| A1 | 正常教材、缺页、一节漏映射、错误前置、练习引用不存在的目标分别编排。 | 合格计划一次开放完整路线。材料缺失标出范围，映射/边/题问题阻止发布。任务重试或应用重启后结果仍一致。 |
| A2 | 让全书、核心、限时路线都引用 A，再标 A 完成并取消。先学没有必要前置的章节。 | 同一完成记录更新各路线正确的分子，分母按各自范围。自由进入生效。初次导入期间可见任务状态与明确的待补件。 |
| A3 | 在节点 A 所在图提交 7 天限时计划与 3 天计划各一次，分别有与无考核资料。 | 7 天可得到单独路线，标出其依据、范围和推荐顺序。无实际范围时注明教材基础。3 天得到优先清单、资料与答疑入口。原全书/核心路线照常可用。 |
| A4 | 从 A 浏览 B 并引用 B 发问。等待时切焦到 C。用另一个标签页保留旧版本并提交。 | 已接受的问题与迟到的答复记在 A。B 作引用可回查。过期焦点的写入返回冲突，前端保留文本并呈现新当前状态。 |
| A5 | A 开 S 并返回，分别导入联调样例中的两种不同 S 成果。相同网络请求重试。 | 焦点恢复 A 一次。续学内容和下一步随支线成果改变，并引用这次实际采用的 S 版本。超时时可基于同一快照重试。 |
| A6 | 参考 `feedback_case`。草稿保存两次，完成一段带多类问题的表达，采纳提示后改正，再独立做新题。 | 通常打字与草稿保存期间可持续书写。反馈指向被核查版本，类别可复合。修正状态单独保存，有独立表现才展示相应能力证据。 |
| A7 | 先不作答直接标 A 完成，然后在 B 独立解释 A 的一个目标。独立完成后回看证据。 | 自行完成更新相应路线。B 的实际表现可以支持 A 的准确目标，记录仍在 B。重复浏览及仅按提示改正都不扩张证据。 |
| A8 | 分别模拟 B 初次求助、缺少证据的重复困难、跳过必要前置后有证据的两次同类卡点，以及完成前置后仍困惑。 | 前两种保留当前焦点并解释。第三种记录强制返回原因、证据和实际前置。第四种继续耐心讲解或建议复习。 |
| A9 | 参考 `keeper_case`。Teacher 给出相关解释，keeper 找到跨课程条目，模拟一个后来被发现有误的关联。 | Teacher 回复可先出现。Keeper 理由、旧版本和关系类型可查。重复引用可合并显示。不适合的提示按原上下文撤回，原记录可读。 |
| A10 | 用 `tool_cases` 对照[工具契约](06-agent-tools.md)，模拟已知引用、无命中、跨图关联、公开来源读取失败和考中调用。 | 已知引用回到确切版本。跨图读取在当前学习者范围内。公开摘要查不到原文时不会成为教材依据。考中规则问答保持独立，工具失败有明确结果。 |

## 从学习目标开始

| 编号 | 准备与操作 | 通过条件 |
| --- | --- | --- |
| G1 | 只输入样例目标，等待来源、里程碑和连续候选备好。点开各候选再采纳任意两个。 | 来源可查看，推荐理由和先后关系可理解。阶段显示里程碑与实际产出。采纳才写入学习图，完成与掌握状态独立。 |
| G2 | 写下两份成果，手动整理到已有节点，再整理为新节点。 | 两处都保存所选版本与汇总。新节点可直接浏览，原图、原记录与当前焦点可继续用。 |
| G3 | 支线内继续当前问题，然后提出系统学习一个新主题。 | 范围内可由用户请求后续建议，扩成系统学习时给新图选项。新图附原节点链接，保存起因和当时版本。 |
| G4 | 为原图导入同目标教材，预览 A 的等价映射与 B 的新增要求，接受方案。 | 同一图中有正式主线。A 沿用稳定 ID、完成与已有证据，并可看到教材出处。新增要求有相应学习、题目和新的证据判断。旧路线、节点与原文仍可打开。 |
| G5 | 让 teacher 在新路线一个合适的任务里用上原学习成果。另用一个与旧成果无关的问题作对照。 | 适用时能从原始记录讲得更具体并回查版本。无关时按当前问题答复。导出所选笔记在外部 Markdown 编辑器可读。 |

## 计时自测

| 编号 | 准备与操作 | 通过条件 |
| --- | --- | --- |
| E1 | 看预览，从工作台、引用和导出分别尝试读题。协商开卷条件，最后确认。 | 确认前仅范围与规则。最终确认时试题才开放，预览版、起止时间和许可条件一同冻结。 |
| E2 | 开考后另开标签页，尝试切焦、开支线、看题解和解题求助。正常更新作答后刷新。 | 权威焦点和时间一致。作答可保存并回显。规则类回复可用，解题求助只得到鼓励与规则说明。只有本场允许资料可从学习工具读取。 |
| E3 | 提前交卷重复点击。另起一场，保存部分过程后关页面并等到超时。 | 一次正式结果，答卷只含按规则已保存的答案。到点状态在服务端终结。解锁保留考试焦点。 |
| E4 | 报告一个有歧义/错误的题，模拟可及时勘误与临近截止才核实两种时机。 | 正常勘误只修题面且有版本、时间和提示。来不及作答时作废并说明。原截止、旧题和写下的过程可查。 |
| E5 | 在复盘中进 B 查看概念，做一道短题，再回到讲卷进度。 | 自测节点一直是焦点。原答卷不改，短题和解释另存。能区分回忆与应用，并按实际展示的目标回查证据。 |

## 比赛演示与可复查交付

两段 AgentArts 工作流都需完成真实部署和应用调用。每段留一条记录，写用户动作、请求/结果版本、实际部署标识、结构校验、来源可回查结果以及耗时。另用一次超时、输出不合法或来源缺失测试应用的有效报错及重试。官方提交要求以届时的赛题页面为准。[华为 ICT 大赛赛题页](https://e.huawei.com/cn/talent/#/ict/innovation-details?zoneCode=027425&zoneId=98269700&compId=85132021&divisionName=%E4%B8%AD%E5%9B%BD%E5%8C%BA&type=C002&enrollmentDeadline=2026-11-30%2023%3A59%3A59)

- 若 G1、G2、G4、G5 跑通，主展示「给目标 → 选候选 → 留成果 → 原图补教材 → teacher 用上旧成果」。
- 否则可展示「教材编排 → 原节点开支线 → 返回原处 → teacher 用实际支线成果接着教」。两个入口各自的首版验收继续执行。
- 演示至少有一次点击查看真实出处、一次改变输入得到不同教学结果。准备同样例的本地联调模式排查问题，并在现场明确当前调用模式。
