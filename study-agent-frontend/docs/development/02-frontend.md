# 前端开发任务书

你负责电脑网页。交付从两种入口到真实学习、查看出处、练习和复盘的完整用户路径。按 [共同起步](00-start.md) 和 [共用开发契约](01-contract.md) 实现 API。后端可用前先读 [examples.json](examples.json) 做数据层 mock，同一页面之后切换到联调 API。

## F1 · 入口、图和学习工作台

1. 建立桌面端应用骨架、路由和一层业务 API 客户端。首轮最少支持图列表、工作台、教材准备和目标准备。用基准样例可一键进入已有学习状态。API 客户端提供同形的 mock 与服务端实现，页面组件共享。
2. 工作台同时展示**当前学习**和**正在查看**。建议将当前焦点及返回入口固定在工作区。图可用现成组件，配一份键盘可操作的节点列表。路线显示推荐次序，前置边和关联边可以分别辨认。点一下图节点只查看，按「在此学习」才切焦点。图很大时，先支持按路线切换和定位当前节点。
3. 默认工作区依次给用户目标、阅读起点、出处、草稿区、问答与反馈。焦点节点保存可恢复的阅读位置和最近问题。浏览 B 时保留 A 的编辑和学习上下文，明确提示「提问记在 A · 引用 B」。支持将显示的段落或记录加入问题引用。数据采纳、提交、进入与浏览用不同按钮。
4. 从 A 主动开支线时展示起因或选中的问题，创建成功后把焦点和输入区切到 S。返回 S 的出发点后恢复 A 的学习位置，马上展示「正在接续」。等任务完成在 A 下显示答复与可点开的原记录。失败时 A 仍可浏览和提问，并提供重试这次接续的入口。
5. 在引用面板明确展示标题、版本、页码或段落、选中原文。源文件支持独立打开，打开引用不切焦点。引用已修订或暂不可取时显示实际状态，能看到旧版时直接显示对应版。

**交付检查**。能用点击 A、浏览 B、在 A 发问、开 S、记下成果、回 A、打开 S 的原文做一段现场演示。刷新后从服务端恢复焦点。等回复时切到另一个节点，回复仍出现在原归属节点。

## F2 · 教材导入和目标式探索

### 有教材

- 先选择系统学习或限时任务。系统学习预选全书，可确认学习目的、期限与习惯。限时可填截止需求、考查范围，附重点和样题。Teacher 预填推荐选项，用户确认后开始备课。
- 上传、解析、分组备课、编排、验收、待补件与完成有清楚状态。离开页面后可从图列表或任务栏回到同一任务。已有图补教材时原图能继续读写。对初次导入，正式路线完成发布后再开放学习节点。
- 全书路线与核心路线各显示计数。实际编排成功的限时路线另列。少于一周的结果呈现为参考清单与资料，可在相应图中和 teacher 对话。目标入口无正式路线时展示里程碑及产出。
- 路线修订或补教材建议给出保留、扩展、新增及出处预览，由用户明确采纳。在同图增加教材后可切换路线与探索视图，旧节点及进度保持可回查。

### 从目标开始

- 输入目标，资料可选。可编辑最近里程碑，查看公开来源和同目标相关的建议。候选卡显示标题、推荐理由、来源、前后关系与已备学习内容。灰色之外加「建议」文字，触屏与键盘均可打开。
- 用户可忽略、采纳一个或多个。采纳给出正式节点及其阅读、活动入口。只要资料允许，用户也可以先从靠后的候选开始。用关系提示解释真实前置。
- 教材主线的自由聊天继续当前章节。支线确有深入意愿时可请求候选，teacher 给出新图建议时提供显式确认。新图展示来自哪门课、哪条记录或问题。
- 手动 merge 先选记录和版本，再选「整理到已有节点」或「新建阶段整理」。结果可打开汇总及每个出处。合并后用户可继续原焦点，也可显式去整理节点学习。

## F3 · 记录、理解反馈与关联

- 在笔记/推导输入区连续保存草稿，显示保存中的状态与已保存时间。版本冲突保留屏上文本，允许对照或另存。点击「这段写完了」在当时的焦点提交一份版本，teacher 选择是否核查。自由问答另支持引用已保存版本并请 teacher 检查。
- 反馈项支持多个类别和程度。先显示短提示，用户点开看所对应的原话、依据与下一步建议。对不同版本的反馈可回看哪句已经修正。独立过关题结果或练习证据单独链接。
- 每个节点提供自行标记完成的动作。掌握视图展示目标和可查证据、是否带资料或提示。Teacher 主动邀请做过关题时用户可做、稍后做或跳过。被建议复习时说明原因。只有后端返回已验证的强制返回事件时改变焦点，并显示缘由。
- Keeper 提示放在关联区，展示为什么有关与旧内容入口。Teacher 正常回复可先显示。关联的撤回更新到原提示条目并解除可点击建议，已打开的来源本身仍可读。
- 笔记/图菜单提供导出 Markdown，实际下载后可以独立阅读。导出状态、无记录、仅导出当前节点和失败重试都有文案。

## F4 · 计时综合自测和复盘

| 阶段 | 网页行为 |
| --- | --- |
| 预览 | 显示时长、范围、开卷条件、连续计时、焦点锁与交卷方式。必要时给用户与 teacher 商议规则的入口。节点预览与确认弹窗分别提醒，只有最终按钮「开始计时」发 start。 |
| 考试中 | 用拿到的 `deadline_at` 与 `server_time` 校正倒计时。每次重新打开读场次。按题保存，清楚显示已保存或待同步。开放已获准的资料、规则问题、报告疑似错题和确认交卷。普通学习、切焦及可泄题的关联面板停用。 |
| 题面更新 | 把题号、勘误时间和需要更正的文字放在对应题目。保持已输入内容。作废题标记作废理由，仍能看过往答案。 |
| 交卷 | 提前交卷需确认。到时轮询读取正式答案和终态，由服务端宣告实际结果。保留考试节点为焦点，开始考后步骤。 |
| 复盘 | 展示提交时答卷，再按题逐步显示解释和复测。用户可以查知识节点，当前焦点与考后问答仍属于考试。相关目标可另显新证据入口。 |

刷新、超时、锁定和重试用共用错误码处理。考前试题隐藏由 API 保障，页面预览也仅读预览接口。实现完成用两个标签页模拟焦点过期和考中重开场次。

## 前端交付件

- 能运行的 `web/`、实际启动命令、样例开关说明和与后端联调的 base URL 用法。
- 两种入口、工作台、考试与复盘的可点击路径。提交界面截图或短录屏，并按[验收表](05-acceptance.md)记录真实结果。
- 普通加载、空状态、待补件、任务失败、版本冲突、计时到点和引用版本不可用都有可读提示。关键动作用文字标明，键盘可选节点、确认和打开出处。
