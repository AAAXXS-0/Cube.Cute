# 学习辅助 Harness 仓库指南

- 从 [README](README.md) 找到自己的任务书。开发前读[共同起步](docs/development/00-start.md)、[共用开发契约](docs/development/01-contract.md)与[联调数据](docs/development/examples.json)。具体教学行为按对应任务书和[设计索引](docs/design-index.md)追溯。
- 电脑网页优先，首版以键入和 Markdown 为主。有教材、从目标开始两个入口都按各自场景验收。比赛版优先完成题目要求、实际部署和可复现演示。教材编排与验收、支线返回续学需要实际接通 AgentArts。
- 保持浏览位置与学习焦点分开，保留当时的记录与来源版本。节点完成、修正和独立掌握证据分别记录。应用持有状态，教学服务返回建议和结果，状态变化通过约定的应用动作落库。
- 在自己的职责范围内实现。共用契约有变动时同时更新样例、验收及受影响的实现。mock 用于明确标记的开发联调，比赛验收保留真实运行记录。
- [AGENT.md](AGENT.md) 保留原始项目背景、讨论方式和逐轮定稿。早期材料中的备选做法见[设计索引](docs/design-index.md)。原始讨论与现行开发约定产生歧义时，按共享契约列出具体冲突交由对应负责人核实。
