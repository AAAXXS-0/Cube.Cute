# 学习辅助 Harness · 应用后端开发交接

这是电脑网页首版的一份角色交接包。两种学习入口及共同验收按同一套产品设计执行。

第一份可交付结果是实现可持久化的节点、焦点、支线返回与指定版本读取，再用同一份样例接入 mock teacher。

## 从这里开工

1. 读 [AGENTS](AGENTS.md) 和[共同起步](docs/development/00-start.md)。
2. 打开 [应用后端开发任务书](docs/development/03-backend.md)，从第一项任务开始。
3. 对照[共用开发契约](docs/development/01-contract.md)和[联调数据](docs/development/examples.json)实现。
4. 按[联调与验收](docs/development/05-acceptance.md)记录结果。使用[协作指南](CONTRIBUTING.md)与队友交接。

## 直接交给开发 Agent

> 读 AGENTS.md、共同起步、共用开发契约、后端任务书及 examples.json。按后端任务书从 B1 开始实际开发，先把焦点、支线与指定版本读取做进真实持久化，再根据共用样例交付可供前端联调的 API 和可切换的工作流适配器。
