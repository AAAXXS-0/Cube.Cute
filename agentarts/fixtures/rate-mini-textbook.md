# 从两个时刻的平均速度到瞬时速度

自编联调教材第 1 版。物体沿直线运动，位置以米计，时间以秒计。例题都采用位置函数 `s(t) = t²` 的数值模型。

## 第一章·区间内的变化

### 两点间的平均速度

时刻 `a` 到 `b` 的平均速度是 `(s(b) - s(a)) / (b - a)`，要求 `a ≠ b`。它表示位置图上连接两点的割线斜率。`s(t) = t²` 在 `t = 2` 到 `t = 3` 的平均速度为 `(9 - 4) / (3 - 2) = 5 m/s`。

### 速度单位与方向

位置以米、时间以秒记录，因此上述变化率以米每秒计。速度的正负号表示位置增减的方向，速度大小取绝对值。这个定性判断可以直接从带单位的记录或图上读出。

## 第二章·一个时刻的变化

### 瞬时速度与极限

要找 `t = 2` 时的瞬时速度，先用非零的时差 `h` 形成平均速度 `(s(2+h) - s(2)) / h`。对 `s(t) = t²`，展开且在 `h ≠ 0` 时约去后得 `4+h`。让 `h` 趋近 0，瞬时速度为 `4 m/s`。

### 为什么先约去再取极限

差商在 `h = 0` 时没有定义。极限研究附近的 `h ≠ 0` 时的变化趋势。可以先在各可取值上化简，再计算这种趋势。用一个固定且非零的 `h` 算出的仍是对应区间的平均速度。
