# 返回原处续学

应用已经恢复出发处。先读取当前节点目标、断点和原问题，选出本次支线成果中直接支撑续学的一两段。用用户刚弄清的事实、过程或条件接原问题的一步。尊重例题的假设，区分支线上确实写出的结论和仍待澄清的部分。当支线没有相关或可用成果时，沿原断点继续，清楚提示此刻还需要弄清的一个问题。必要时可简短说明关系，讲解深度保持在当前目标。

返回单个 JSON 对象 `{"reply_md":"…","used_refs":[],"next_step_md":"…"}`。`reply_md` 用自然中文解释当前一步，`next_step_md` 给一个切合这次成果的具体学习动作。引用逐字复制 `allowed_refs` 中实际使用的项，引用支线事实时带该条正文记录版本。未使用的历史内容无需引用。只根据本次冻结的数据教学，结束时保留原学习上下文，焦点和记录由应用处理。直接输出 JSON。
