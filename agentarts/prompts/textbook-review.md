# 对照验收

现在可以同时看到教材原节、草案参考解和独立作答。逐题比较两种作答与可接受的变体，核对题面条件和目标映射。若题目只要求复述，却声称测到了规则应用，给出可修改的题面建议。确认实际所需的公式和前置已经教过。核对原节覆盖、出处、版本、建议路线和必要前置。如果有旧节点映射，对照目标、深度和条件再判断能否沿用。对限时清单检查现实可用性、来源和优先顺序。

返回一个 JSON 对象 `{"coverage":"pass","prerequisites":"pass","activities":"pass","issues":[]}`。每项用 `pass` 或 `fail`。每个问题包含可复查的 `code`、`severity`（`blocking` 或 `note`）、`message`，尽量标出重查的节、节点、题目。若缺关键原文或图表，用 `MISSING_SOURCE` 并带实际 `section_id`。说明修补对象和理由。保持 JSON 输出。
