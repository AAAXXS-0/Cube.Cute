# 学习辅助 Harness · 产品、教学与 AgentArts 开发交接

这是电脑网页首版的一份角色交接包。两种学习入口及共同验收按同一套产品设计执行。

第一份可交付结果是用自编短教材和两份不同支线结果验证教材编排与验收、支线返回续学两段 AgentArts 工作流。

## 从这里开工

1. 读 [AGENTS](AGENTS.md) 和[共同起步](docs/development/00-start.md)。
2. 打开 [Teaching 与 AgentArts 开发任务书](docs/development/04-teaching-agentarts.md)，从第一项任务开始。
3. 对照[共用开发契约](docs/development/01-contract.md)和[联调数据](docs/development/examples.json)实现。
4. 按[联调与验收](docs/development/05-acceptance.md)记录结果。使用[协作指南](CONTRIBUTING.md)与队友交接。

## 直接交给开发 Agent

> 读 AGENTS.md、共同起步、共用开发契约、Teaching 与 AgentArts 任务书及 examples.json。按任务书从 T1 开始实际开发，验证 AgentArts 的教材编排与验收及支线返回续学，交付两段流程的结构、调用参数和验收记录。并行补齐 teacher 和 keeper 的约定样例。
